# XUpdater

O X Updater é um aplicativo homebrew para Nintendo Switch que facilita o download, a instalação e o gerenciamento de atualizações e conteúdos diretamente pelo console, sem a necessidade de remover o cartão microSD.

Funcionalidades

Atualização do Atmosphère: baixa e instala diferentes versões do pacote IndicaX, preservando configurações e arquivos importantes.

Download de firmware: permite baixar versões do firmware do Nintendo Switch, preparando os arquivos para instalação pelo Daybreak.

Mods e traduções: disponibiliza o download de modificações e traduções por meio de catálogos do GitHub.

Atualização automática: verifica novas versões do próprio X Updater e permite atualizá-lo diretamente pelo aplicativo.

Instalação offline: oferece suporte à instalação de pacotes locais, sem conexão com a internet.

Segurança e recuperação: verifica a integridade dos downloads com SHA-256, realiza backups e oferece mecanismos de recuperação em caso de atualizações interrompidas.

Repositórios personalizáveis: permite configurar fontes alternativas para os catálogos de downloads.

Simples, prático e seguro

Gerencie atualizações, firmwares, mods e traduções em uma única interface, utilizando apenas os controles do Nintendo Switch.
